# 変更内容

- 初期値を45分→120分、休憩5分・通知音ON・自動起動OFFに統一。
- Remind待機状態、後回し、通常解除を削除し、Work ⇄ Breakの自動サイクルへ変更。
- Rustの独立したタイマー状態機械と単体テストを追加。
- Windowsの稼働時間時計とセッション通知でロック・スリープを除外。
- 30秒待機＋再確認の緊急解除をRust側で検証。休憩中のリセット・設定変更・一時停止を拒否。
- 日本語のダークUI、通常画面、中央最前面の休憩画面、短い終了通知。
- 右クリックのネイティブトレイメニュー、×で格納、トレイから完全終了。
- 設定値の範囲検証、保存失敗表示、バックアップを伴う設定保存。
- 自動起動の既存実装を保持し、派生版専用の登録名へ変更。
- 浮遊ウィジェット、カスタム健康メッセージ、言語切り替え、アイドルリセットを削除。
- 不要なsys-locale、autostartプラグイン、直接のwindowsクレート依存を除去。
- CSPとフロントエンド権限を制限。外部通信コードなし。
- 開発ビルド専用の60秒／30秒モードを追加。
- Windows CIに単体テスト・exe／NSIS生成・Artifacts出力を追加。
- 元のMIT LICENSE・Git履歴を保持、NOTICE・日本語README・ビルド手順を追加。

## 意図的な仕様判断

- 休憩は全画面ではなく中央の最前面ウィンドウ。OS全体の操作禁止や他アプリの強制終了はしません。
- 確実な判定のため、30秒長押しではなく許可された2段階方式を採用。
- 無操作は離席とは限らないため、アイドル検出は削除。
- ロック中・スリープ中は休憩時間も停止。
- 起動時は保存された作業時間から新規開始。中断状態の復元はしません。
- 指定どおりトレイの「終了」は常時利用可能。
